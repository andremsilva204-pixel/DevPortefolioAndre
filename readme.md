# DevPortfolio - Sistema de Gestão de Portfólio

Aplicação web desenvolvida para gestão e exposição pública de projetos de desenvolvimento de software, com suporte para utilizadores autenticados e persistência de dados na nuvem.


## 🛠️ Tecnologias Utilizadas

* **Backend:** Node.js, Express.js
* **Base de Dados:** Turso (LibSQL)
* **Frontend:** HTML5, CSS3, JavaScript 



## 🚀 Funcionalidades

1. **Operações CRUD de Projetos:** Criar, listar, editar e eliminar projetos diretamente interligados à base de dados Turso.
2. **Área de Administração Protegida:** Acesso restrito via autenticação de utilizador.
3. **Exposição Pública:** Visualização pública dos projetos sem necessidade de login.
4. **Design Responsivo:** Adaptado para mobile, tablet e desktop.
5. **Alternância de Tema:** Troca entre Light Mode e Dark Mode.
